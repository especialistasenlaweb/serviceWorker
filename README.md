# Ejemplo Service Worker

Ejemplo educativo para demostrar cómo un Service Worker
puede almacenar recursos en caché y permitir que una página
web funcione sin conexión.

## Recursos almacenados

- index.html
- Bootstrap CSS
- Bootstrap JavaScript

## Cómo probarlo

1. Abrir la aplicación mediante un servidor web.
2. Entrar a la página.
3. Abrir las herramientas de desarrollo.
4. Comprobar el Service Worker.
5. Desconectar Internet.
6. Recargar la página
